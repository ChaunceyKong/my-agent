备选链最多两次降级，保存时检查所有上游路径，拒绝循环、自引用和超深链；被引用配置不能删除。429 使用可取消的 2／4 秒退避，5xx／网络故障最多重试一次；单次 30 秒、累计 120 秒。401、Ollama 服务未启动、授权／预算／能力错误、聊天已收到流字节及已经执行工具的调用不会自动切换。需要 CEO 处理的失败安全暂停，并显示受控提示。

Run 保留配置路由；完成回复和 Turn 另存实际模型身份。界面显示持久化配置 ID，当前名称仅作参考；尝试记录不等于成功结果。每个候选分别核验云端及工具结果授权，不自动授予。工具效果执行后的同一 Turn 固定实际模型，不因降级重放效果。

四套团队为自媒体、商业、文学和开发，分别包含 5／5／5／4 个角色。导入在单个事务中创建用户副本和启用成员，不发模型请求、不启动任务；重复导入生成唯一名称。运行、暂停或未闭合效果阻止导入。复制编辑只提交身份、提示与模型字段，工具默认全部拒绝；创建后通过普通 Agent 编辑页显式授权。修改副本不会改变内置模板。

Electron 使用隔离的临时数据库／工作区和本机假 Provider，覆盖以下行为：

- 配置重启持久化、循环与引用删除原子拒绝、每候选独立同意且同意前无请求。
- 5xx 主模型两次尝试后切换备选，配置与实际模型分别持久化。
- 缺失备选授权暂停且不外发；429 退避取消后无迟到重试。
- 401 不降级；部分文字或原生工具字节失败不生成完成消息、不执行工具、不切换。
- 备选模型真实写文件后保持固定，效果记录一次，重启不重放。
- 四套团队共 19 个默认拒绝工具的可编辑角色，重复名称唯一、重启成员持久化。
- 完整提示词预览、复制编辑与原模板隔离、暂停任务下整队导入拒绝。

完整回归发现并修复模型尝试事件覆盖调度理由的问题，新增回归保留真正的选人理由。旧 401 验收同步至安全暂停契约，增加持久化暂停及无虚构完成回复断言。

## 本地体验与未验证项

运行 `npm run dev`。在模型设置中配置主模型和备选链；发送前分别确认各云端候选的外发范围。Agent 页选择模板导入模型，预览后导入当前群聊，或复制单个角色进入编辑。工具权限须在副本创建后显式开启；审批与执行仍是独立步骤。

以下仍需手工验收，不能由假 Provider 测试认定通过：

- 用户批准的真实外部模型、真实密钥加密及原生工具协议。
- 实际安装运行的 Ollama 和具体模型的能力。
- 打包后的 Windows 原生目录选择器。
