## 本地体验

运行 `npm run dev` 启动桌面开发版。在模型中心配置模型后，创建 Agent，并在群聊中加入、启用成员。通过输入框上方成员选择器插入点名；手输 `@名称` 仅作为普通文字。

多成员无指派时，需要配置调度模型，否则任务会暂停等待 CEO。审批效果完成后点击“继续当前任务”或明确指派；系统不会自动重放已执行工具。重启遗留进程须先手工停止／核验，再使用界面确认入口；审计记录明确这是人工声明，应用没有声称验证了 OS 进程状态。
